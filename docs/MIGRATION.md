# Fresh plugin v0.1 repository

Extracted from `openbexi_spell` commit
`d4b0ed98f186346ea9e9af53816af2578953042c` on 2026-10-10. Retained components are
the bounded explicit-import SDK/TIME/common policy, DSS engine/catalogue/packets/
HTTP and binary TCP servers, evidence utilities, essential original manuals and
source archive. `MIGRATION.json` contains hashes of their original bytes.

DSS catalogue loading now uses packaged `dss/data/satellite_database.json` rather
than a path outside the distribution. The distribution is
`openbexi-spell-plugin` 0.1.0. Runtime imports are `openbexi_spell_plugin`, the
retained `openbexi_spell` SDK and its bounded `spell.lang` alias. The deterministic
test fixture and adapter are explicit new increments; original Kafka transport
code is retained and has no mandatory dependency for the local fixture.

Historical web/backend implementations, release receipts, old versioned docs,
screenshots and full Git history are archived outside the fresh projects under
`C:/projects/.openbexi-archive/20261010-split/`. The verified bundle includes
branches, tags, stash and worktree heads. Old acceptance claims retain their old
identities and are not promoted to full SPELL compatibility in this v0.1.

Both projects have independent fresh local Git histories. Remote GitHub changes
require the owner's requested scope; no credentials, runtime data, qualification
caches, old image assets or historical release series belong in this Git.
