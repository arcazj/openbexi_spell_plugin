# Durable ASRUN component — native activation pending

The disk writer is prepared for qualification. It is not active in the native build yet; mandatory memory acceptance must be established before enabling it. The original audit files remain in the existing native temporary workspace in this candidate.

`audit_file.H` writes synchronously without an asynchronous queue. Each acknowledged write completes `fdatasync`; directory entries complete `fsync`. Restore uses a fixed 4 KiB buffer. Disk-backed private directories, exclusive writer locks, regular-file permissions and no-follow opens are required. tmpfs/ramfs are rejected. The host must provide a private retained volume; the component never deletes required records.

Reset and restore keep the previous inode under an exclusive archive-generation name, synchronize it, then create the replacement. At most 1,024 archive names per active path are searched; exhaustion fails explicitly. An interrupted append's incomplete tail is preserved and rejected, rather than silently truncated. Write, sync, lock, policy and restore failures emit a fixed `V08_AUDIT_FAILURE` label and terminate the participant with exit 74, without an acknowledged retry. This provides explicit failure, not transactional rollback of an already uncertain record.

Component tests execute actual concurrent writes, a second writer denial, process restart, retained generations, exact ASRUN sequence/format, kernel file-size refusal and incomplete-tail preservation. Syscall-injected interrupted/partial/sync failures are separate component probes. The new CI workflow creates a private 16 MiB ext4 loop filesystem, fills it to actual ENOSPC, verifies every acknowledged record, releases only an expressly expendable fault-fixture reserve and checks restart behavior. It retains the raw audit bytes and source-bound receipt before unmount. Its actual result must be retrieved; a workflow definition is not a pass.

Native integration still requires the worker volume mount, resource and disk accounting, all required native record checks, host retention, live full-disk behavior, restore and crash qualification. The audit component and raw records remain writable by their native participant; tamper-resistant audit isolation and the independent security review remain open security work. No production migration or full release qualification is implied.
