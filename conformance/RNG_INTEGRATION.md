# Ranging integration candidate

The accepted ranging donor recipes are composed before wheel creation: the
original helper, the driver proxy and persistent Ground state. Native checkpoint
identity binds both recipes. Installed source and RECORD verification remain
mandatory; no installed-file overlay qualifies this candidate.

Run `run_rng.py --catalog-only --image <immutable-id>` for the eight catalog
controls. Only GetBasebandNames, GetAntennaNames and Example 174 can qualify.
Run `run_rng_state.py --image <immutable-id>` for the 21 independent activity,
schedule, migration and fencing controls; these promote no additional rows.
The retained 36-case donor suite includes observations of the legacy conflated
state and is not the oracle for the corrected state model.

The [current checkpoint](../docs/LANGUAGE_CHECKPOINT.json) now includes the
fresh reproducible native/driver builds, installed catalog/activity runs and all
33 regression suites. Three catalog requirements are qualified; the 21 activity
controls promote no additional rows. The retained 28 real-RPC tests and 47
legacy-driver/migration tests support that composition. Full ranging semantics,
final distribution and v0.5/v0.6 acceptance remain open.
