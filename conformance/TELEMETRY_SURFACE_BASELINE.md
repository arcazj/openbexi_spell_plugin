# Remaining telemetry surface

The accepted observation checks cover individual acquisitions, comparisons and
failure policies. The full GetTM and Verify contracts remain open. The existing
report explicitly excludes actual source quality/validity/link failures, the
one-minute timeout example, and the native Display loop for verification details.

These twelve probes exercise the unchanged composed image with actual DSS fault
scenarios, original-schema RPC and native helpers. A fixture reset retains the
old scenario evidence, refreshes the transport epoch, and provides a good source
for recovery. No assertion that a feature is qualified follows merely from the
probe returning success; source packet bytes, the SQLite evidence and emitted
messages must be independently checked.

The baseline must be frozen and executed serially after the pending command and
limit native pipelines. No telemetry implementation change has been made here.
